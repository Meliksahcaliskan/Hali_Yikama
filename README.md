# Ezgi Halı Yıkama — Demo Web Sitesi

Halı yıkama ve ev temizliği firması için demo web sitesi.

**Canlı demo:** https://meliksahcaliskan.github.io/Hali_Yikama/

## Sayfalar
- `index.html` — Ana sayfa (hizmetler, fiyatlar, hızlı fiyat hesaplama, SSS)
- `siparis.html` — 3 adımlı sipariş: halılar & fiyat → adres & alım zamanı → onay
- `panel.html` — Mağaza paneli (demo): gelen siparişler ve durum takibi

## Notlar
- Fiyatlar ve iletişim bilgileri `js/data.js` içinden değiştirilebilir.
- Demo sürümde siparişler tarayıcının `localStorage` alanında saklanır; gerçek sürümde bir sunucu/veritabanı gerekir.
- Online ödeme yoktur, ödeme teslimatta alınır.
